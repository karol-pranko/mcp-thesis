\streszczeniepracy{
Praca dotyczy wydajności i~bezpieczeństwa komponentów bramy pośredniczącej w~standardzie Model Context Protocol (MCP), integrującej systemy agentowe oparte na modelach językowych z~relacyjną bazą danych o~złożonym schemacie. Zaprojektowano i~zaimplementowano w~języku Python 3.12 bramę zawierającą: selekcję schematu łączącą wyszukiwanie leksykalne i~wektorowe (RRF) z~autorską ekspansją grafową o~tabele mostkujące, wielokolumnową paginację kursorową keyset, transfer danych binarnych poza ramką JSON-RPC (Out-of-Band) z~analitycznym modelem progu opłacalności oraz walidator zapytań oparty na analizie drzew AST wykonywany w~puli procesów. Na zbiorze \wynNQueriesEn{}\,zapytań Text-to-SQL w~schemacie o~skali 1000 tabel ekspansja grafowa istotnie zwiększyła czułość selekcji tabel (Table-Recall@5 \wynRecallGraphFive\% wobec \wynRecallRrfEight\% dla RRF@8 i~\wynRecallBmEight\% dla BM25@8 przy równym budżecie tabel), redukując objętość DDL w~prompcie o~ponad 99\% względem pełnego zrzutu schematu (\wynFullDumpTokens{} tokenów). Paginacja keyset zachowuje stałe opóźnienie na relacji 1 mln wierszy (\wynKeysetDeep~ms przy offsecie 950\,000 wobec 429~ms dla OFFSET/LIMIT), transfer przez pamięć współdzieloną (SHM) na jednym węźle jest szybszy od kodowania Base64 dla ładunków powyżej \wynSstarLoopShm~KiB, zgodnie z~modelem progu, a~wieloprocesowa walidacja AST obniża medianę opóźnienia pętli zdarzeń przy 100 klientach z~\wynCcSyncHundredLagMed{} do \wynCcPoolHundredLagMed~ms. Walidator zablokował wszystkie \wynSecInjection{} badane wektory SQL Injection bez fałszywych alarmów. Wyniki eksperymentalne potwierdziły nadrzędną hipotezę badawczą w~odniesieniu do zaimplementowanych komponentów bramy MCP.
} % koniec streszczenia

\slowakluczowe{Model Context Protocol, systemy agentowe, bazy danych, duże modele językowe, paginacja kursorowa, pgvector, bezpieczeństwo AI, Text-to-SQL}

\thesisabstract{
This thesis investigates the performance and security of the components of a Model Context Protocol (MCP) gateway integrating LLM-based agent systems with a relational database having a complex schema. A gateway was designed and implemented in Python 3.12 featuring: schema selection combining lexical and vector retrieval (RRF) with foreign-key bridge-table expansion, multi-column keyset cursor pagination, out-of-band binary data transfer outside the JSON-RPC frame with an analytical break-even model, and an AST-based query validator executed in a dedicated process pool. On a benchmark of \wynNQueriesEn{} Text-to-SQL queries over a 1000-table schema, graph expansion significantly increased table retrieval recall (Table-Recall@5 of \wynRecallGraphFiveEn\% versus \wynRecallRrfEightEn\% for RRF@8 and \wynRecallBmEightEn\% for BM25@8 at an equal table budget), reducing prompt DDL volume by over 99\% compared to the full database dump (\wynFullDumpTokensEn{} tokens). Keyset pagination maintains constant latency on a 1-million-row table (\wynKeysetDeepEn~ms at offset 950,000 versus 429~ms for OFFSET/LIMIT), shared-memory transfer (SHM) on a single node outperforms Base64 encoding for payloads above \wynSstarLoopShmEn~KiB consistent with the analytical model, and multi-process AST validation reduces the median event-loop lag under 100 concurrent clients from \wynCcSyncHundredLagMedEn{} to \wynCcPoolHundredLagMedEn~ms. The validator successfully blocked all \wynSecInjectionEn{} tested SQL injection attack vectors without false positives. The experimental findings confirm the overarching research hypothesis for the investigated MCP gateway architecture.
} % end of abstract
